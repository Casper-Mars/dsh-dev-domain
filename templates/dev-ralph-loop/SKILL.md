# Ralph Loop（单任务循环）

## 循环结构

```
对齐 → 派发 → 自检 → 独立验证 → 交付
              ↑         │
              └── 迭代 ←┘
```

## 各阶段要点

1. **对齐**：复述目标与验收标准；有歧义先问，不带着猜测开工。
2. **派发**：按派发契约组装上下文卡片，选对 preset，设置足够超时。
3. **自检**：检查产物是否存在、命令是否真的执行、退出码是否为 0。
4. **独立验证**：编码任务必须由 Tester 复跑验收命令，Leader 不代替验证。
5. **交付**：给出证据与未覆盖项，然后停下等用户确认。

## 迭代规则

- 不通过 → 带着**具体失败证据**回到派发，不重复同一句指令。
- 同类问题连续出现两次 → 先修流程（补规范 / 补测试），再继续。
- 每轮迭代只改必要范围，禁止顺手重构。

## 状态追踪

维护任务状态表（编号、任务、优先级、状态、commit），跨会话以文件为准，
不依赖记忆。状态只在有证据时推进：`待开始 → 进行中 → 已验证 → 已交付`。

## 禁止行为

- 跳过独立验证直接交付；
- 用「应该可以」替代命令输出；
- 一个任务未确认就自动开始下一个。
